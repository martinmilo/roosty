# roosty 0.1.0

The first public release. roosty prints a project overview from files in `.roosty/`:
`roosty` for the overview, `roosty show <id>` for one process, `roosty changes` for what
changed since a day, `roosty validate` to check the records, `roosty scan` to update the
entrypoints from the project's own scan script, and `roosty init` to start.
